# Extended kaomoji library (English)

Come here only when the quick table in SKILL.md doesn't fit. **Grep one section, don't read the whole file.**

```bash
rg -A 4 '^## Shrug' reference/kaomoji.md
```

Everything below is **full-width kaomoji** — the default for this skill. Tone tags: `[good]` upbeat / `[soft]` gentle / `[strong]` big emotion / `[deadpan]` dry / `[low]` low-energy.

ASCII emoticons live in a separate fallback section at the bottom. Don't reach for them unless the surface can't render wide characters.

## ASCII fallback

Use **only** when the surface can't render full-width characters (plain-text logs, some terminals, commit messages), or when the user writes in ASCII themselves. Not a style choice.

`:D` `:)` `;)` `:P` `:O` `:')` `:c` `T_T` `>_<` `^_^` `o_O` `-_-` `>_>` `\o/` `o/` `o7` `¯\_(ツ)_/¯` `uwu` `>///<`

## Handle with care

Not banned — these steal the scene. Only when the user has already been joking, and at most one per reply:

- Table flip `(╯°□°）╯︵ ┻━┻`
- Keyboard smash `((((；ﾟДﾟ))))`
- Crying flood `(T_T)` `(ㄒoㄒ)`
- Flopped `_(:3 」∠)_` (fine for genuine fatigue; twice in a row reads as brushing the user off)
- Kaomoji stacking — three or more in one reply
